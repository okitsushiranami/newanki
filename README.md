# newanki

Androidを中心に使えるオンライン単語帳PWAです。実装は `app/` にあります。

## 使い方

1. 公開URLをPCとAndroidのChromeで開き、同じChatGPTアカウントでログインします。
2. PCの「CSV取り込み」でCSVを選び、問題・答えの列と取り込み先を確認します。テンプレートもダウンロードできます。
3. スマホの「単語帳」から「復習する」を選びます。答えを表示したら、ボタンまたは左右のスワイプで評価します。
4. AndroidのChromeメニューの「ホーム画面に追加」でアプリとして開けます。

## 対応内容

- UTF-8（BOM可）とShift_JISのCSV。カンマ区切り、引用符・改行対応。1回1,000枚、2MBまで。
- 日本語/英語ヘッダーの自動判定、ヘッダーなし、任意の列選択、取り込み前プレビュー。
- 単語帳作成・名前変更・削除、カード追加・編集・削除・検索、既存単語帳への追記。
- 問題・答え・補足・タグ、CSV書き出し、学習データ全体のJSON書き出し。
- 間隔反復：難しい→10分、わかった→1日・3日・以降約2.2倍、最大365日。
- 学習履歴、継続日数、日本時間の日別グラフ。定着の目安は復習間隔21日以上。
- 認証された所有者単位のデータ保存。リトライ重複防止と同時更新の検出。
- AIが学習状況を読めるWebMCPツールとJSONエクスポート。自動監視は未設定。

オンライン接続が必要です。APK/Playストア配布ではなく、ホーム画面から起動できるPWAです。スマホ実機でのインストールは未検証です。JSONは分析・バックアップ用の書き出しであり、JSON復元画面はありません。削除は履歴を含めて取り消せません。

将来のAI監視要件は `REQUIREMENTS.md` に記録しています。
